# MR00100 Hacker Portfolio

Single-file static portfolio for GitHub/Vercel.

## Included
- Hacker/Matrix visual theme
- Uploaded profile photo
- Professional About section
- Separate Programming, Cybersecurity, Development and Workflow skills
- Project cards with original SVG artwork
- Security toolkit section

Replace/add any personal GitHub/LinkedIn links in `index.html` when ready.
